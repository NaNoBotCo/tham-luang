# Tham Luang, Drawn · ถ้ำหลวง วาดด้วยคณิต

The 2018 Tham Luang cave rescue, drawn with math, in English and Thai.

https://nanobotco.github.io/tham-luang/ · https://nanobotco.github.io/tham-luang/th/

- `tools/build.py` holds all copy (EN + TH) and writes `docs/index.html`, `docs/th/index.html`, `llms.txt`, `sitemap.xml`.
- `docs/app.js` draws every canvas. Test hooks: `?t=<hours since 00:00 23 June 2018>` fixes the hero; `?card` at 1200×630 renders the share card.
- Photographs are public domain (U.S. Air Force, Royal Thai government) and one CC BY 4.0 (NaN · Mot Dang); each is credited on the page.
